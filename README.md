One word, no topic, no explanation, no second draft: the first word that comes to mind.

## The word

> Petrichor

The smell of rain on dry earth — vivid, specific, and impossible to mistake for safe filler.

## Run it

```sh
python3 main.py
```

The program writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
